# Граф студентов ИРИТ-РТФ 23`

Граф из студентов ИРИТ-РТФ УрФУ, период обучения 2023 - 2027.

В графе представлены данные на момент 7 семестра, то есть последнего учебного. Данные охватывают с 3 по 7 семестр (данных ранее 3 семестр нет).

## Прочая информация

Логика построения графа - какие студенты чаще всего были в группах с другими студентами. Вершины графа - студенты, ребра - студенты были в одной группе.

В графе есть обособленные студенты, так как некоторые ребра были удалены. Вес каждой связи считался 1 / (колво человек в группе - 1).
То есть большие лекции мало учитывались, после этого данные также отфильтрованы с минимально заданным весом, чтобы убрать слабые связи.
