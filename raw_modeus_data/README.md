# Данные Modeus: студенты и дисциплины

Кто в каких учебных группах учился, по семестрам. Источник — система выбора дисциплин УрФУ (Modeus) и расписание. Собрано **2026-09-12**.
Основа для графа связей между студентами (кто с кем пересекался).

## Файл

`students_by_discipline.json` — один файл, сгруппировано по семестрам.

## Структура

```json
{
 "semesters": [
  {
   "semester": 5,                                            // номер семестра
   "courses": [
    {
     "course": "Математические методы для разработчиков 1",  // предмет / слот выбора
     "realizations": [
      {
       "realization": "Теория принятия решений",             // конкретная дисциплина
       "groups": [
        {
         "lesson_type": "Лекционное занятие",                // тип занятия
         "group": "Теория принятия решений Л-01",            // название группы
         "teachers": ["Иванов Иван Иванович"],
         "students": ["Петров Пётр Петрович", "..."]         // состав (ФИО)
        }
       ]
      }
     ]
    }
   ]
  }
 ]
}
```

Уровни: **семестр → предмет → реализация (дисциплина) → группа → студенты**.
Один предмет может иметь несколько реализаций (вариантов на выбор), у реализации — несколько групп (лекция / практика / лаборатория и т.п.).

## Важные оговорки

- **Студенты определяются по ФИО**, не по ID. Полные тройки почти уникальны, но однофамильцы (разные люди с одинаковым ФИО) сольются в одну запись.
- **Крупные группы дают слабый сигнал.** Потоковые дисциплины и физкультура — это сотни человек (до ~1200); лекции — тоже крупные. Реальное знакомство лучше отражают маленькие практические / лабораторные группы. Для графа связей вес ребра стоит делать обратным размеру группы (например, `1/(размер − 1)`).
- Данные — срез на момент сбора; составы со временем могут меняться.
